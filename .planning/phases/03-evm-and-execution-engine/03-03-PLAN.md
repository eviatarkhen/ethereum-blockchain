   ```python
   """Contract address computation.

   New contract addresses are deterministically derived from the
   deployer's address and nonce per the Yellow Paper.
   """
   from ethereum.crypto.hashing import keccak256
   from ethereum.encoding.rlp import rlp_encode, int_to_rlp_bytes

   def compute_contract_address(sender: bytes, nonce: int) -> bytes:
       """Compute the address for a newly deployed contract.

       address = keccak256(rlp([sender_address, sender_nonce]))[12:]

       The nonce is the sender's nonce at the time of deployment
       (before the transaction increments it).

       # SIMPLIFIED: No CREATE2 (salt-based deterministic deployment).
       # Real Ethereum also supports CREATE2: keccak256(0xff + sender + salt + keccak256(init_code))[12:]

       Args:
           sender: 20-byte deployer address.
           nonce: Deployer's nonce at deployment time.

       Returns:
           20-byte contract address.
       """
       encoded = rlp_encode([sender, int_to_rlp_bytes(nonce)])
       return keccak256(encoded)[12:]
   ```

`_op_call()`:
- Pop 7 arguments from stack: `gas, addr, value, args_offset, args_length, ret_offset, ret_length`
  - `addr` is a uint256 -- take last 20 bytes as the target address
- Read input data from memory: `input_data = self.memory.read_range(args_offset, args_length)`
- Determine gas to forward:
  - `# SIMPLIFIED: Forward all requested gas. Real Ethereum uses EIP-150 (63/64 rule): forward min(requested_gas, remaining * 63/64).`
  - Cap at `self.gas_remaining` to prevent over-allocation
- If target has no code (EOA): just transfer value, push 1 (success), consume base call cost
- If target has code:
  - Create new ExecutionContext: caller=self.context.address, address=target_addr, value=value, data=input_data, gas=forwarded_gas
  - Get target storage from world_state
  - Create new EVM instance and execute
  - If success:
    - Write return data to caller memory at ret_offset (up to ret_length bytes)
    - Update target storage in world_state
    - Transfer value from current address to target
    - Push 1 (success) on caller stack
    - Refund unused gas to caller
  - If failure:
    - Push 0 (failure) on caller stack
    - Gas forwarded to callee is consumed (not refunded)
  - Add `# SIMPLIFIED: No DELEGATECALL or STATICCALL. No stipend (2300 gas) for value transfers.`
