- `CHAIN_ID = 1`
- `GAS_PRICE = 1` (round number for educational clarity)
- `GAS_LIMIT = 21_000` (intrinsic gas cost for value transfer)

**Flow:**
1. Generate two key pairs (sender and recipient)
2. Create genesis world state with sender having 10**18 wei (1 ETH), recipient having 0
3. Print initial state: `# BREAKPOINT: world_state, sender_addr, recipient_addr visible`
4. Build unsigned transaction dict: nonce=0, gas_price, gas_limit, to=recipient_addr, value=10**17 (0.1 ETH), data=b''
5. Sign transaction with EIP-155 (v = recovery_bit + chain_id * 2 + 35)
6. Print signed tx: `# BREAKPOINT: signed_tx fields, v/r/s visible`
7. Apply state transition (debit sender value + gas, credit recipient value, increment sender nonce)
8. Print post-transaction state: `# BREAKPOINT: updated balances, gas used`
9. Create block containing the transaction
10. Print final block: `# BREAKPOINT: block hash, block number, transactions`
11. Assert sender balance decreased, recipient balance equals 0.1 ETH
12. Print summary with final balances

Every major step should have a `# BREAKPOINT:` comment listing the key variables a developer should inspect.

**03_token.py** — SimpleToken contract deployment and interaction:

5. Call `transfer(recipient, 1000)` — transfer 1000 tokens
6. Call `balanceOf(deployer)` and `balanceOf(recipient)` — verify updated balances
