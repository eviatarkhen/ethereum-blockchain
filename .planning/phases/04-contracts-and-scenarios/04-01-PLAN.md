Create `src/ethereum/contracts/` package with three files:

**abi.py** — Generic ABI encoding helpers for the simple types used by Counter and SimpleToken:

1. `compute_selector(signature: str) -> bytes` — Takes canonical function signature string (e.g. `"increment()"`, `"transfer(address,uint256)"`), returns the first 4 bytes of `keccak256(signature.encode())`. Import keccak256 from `ethereum.crypto.hashing`.

2. `encode_uint256(value: int) -> bytes` — Returns `value.to_bytes(32, 'big')`. Raise ValueError if value < 0 or value >= 2**256.

3. `encode_address(addr: bytes) -> bytes` — Returns `addr.rjust(32, b'\x00')`. Raise ValueError if len(addr) != 20.

4. `encode_call(selector: bytes, *args: bytes) -> bytes` — Concatenates selector + all encoded args. Each arg should already be 32-byte encoded.

Add `# SIMPLIFIED: Only handles uint256 and address types. Real ABI encoding supports tuples, dynamic arrays, bytes, string.` at module level.

**address.py** — Contract address derivation:

NOTE: `contracts/address.py` is the initial home for `compute_contract_address`. If Phase 3 later creates `core/address.py`, this function should be consolidated there and `contracts/address.py` should re-export from core.

1. `compute_contract_address(sender: bytes, nonce: int) -> bytes` — Implements `keccak256(rlp_encode([sender, int_to_rlp_bytes(nonce)]))[12:]`. Import from `ethereum.crypto.hashing` and `ethereum.encoding.rlp`. Add docstring explaining the formula and the nonce=0 edge case (encodes as empty bytes -> 0x80 in RLP).

**__init__.py** — Empty or with brief module docstring.

Use the import style `from ethereum.crypto.hashing import keccak256` (no `src.` prefix — project uses PYTHONPATH=src convention).

**counter.py** — Hardcoded Counter contract:

**Pre-step: Opcode availability check.** Before writing bytecode, inspect Phase 3 implementation (`src/ethereum/evm/` or similar) to determine which opcodes are available. If Phase 3 is not yet implemented, default to the DIV-based selector extraction pattern (no SHR) and simplified direct-address storage (no SHA3/KECCAK256 opcode). Document the chosen approach in a `# DECISION:` comment at the top of the bytecode constant.

Define `COUNTER_RUNTIME_BYTECODE` as a `bytes([ ... ])` literal. Each opcode line must have an inline comment naming the opcode and its purpose. The contract implements two functions:

- `increment()` (selector `d09de08a`): Loads storage slot 0 (SLOAD), adds 1 (ADD), stores back (SSTORE), then STOP.
- `getCount()` (selector `a87d942c`): Loads storage slot 0 (SLOAD), stores to memory (MSTORE), returns 32 bytes from memory (RETURN).

Function dispatch pattern:
1. CALLDATALOAD offset 0 to get first 32 bytes of calldata
2. Extract 4-byte selector: use SHR by 224 bits if Phase 3 implements SHR (0x1c), otherwise use `PUSH32 <2^224> / DIV` pattern. Default to DIV if Phase 3 is not implemented. Add `# DECISION: Using DIV-based selector extraction (SHR not available)` or `# DECISION: Using SHR-based selector extraction` accordingly
3. Compare (EQ) against increment selector, JUMPI to increment handler
4. Compare against getCount selector, JUMPI to getCount handler
5. REVERT if no match (fallback)

Add helper functions below the bytecode:
- `encode_increment() -> bytes` — returns just the selector (no args)
- `encode_get_count() -> bytes` — returns just the selector (no args)

These helpers should use `compute_selector` from `abi.py`.

**token.py** — Hardcoded SimpleToken contract:

Define `TOKEN_RUNTIME_BYTECODE` as a `bytes([ ... ])` literal with inline opcode comments. The contract implements:

- `transfer(address,uint256)` (selector `a9059cbb`): Loads sender balance from storage, checks sufficient balance (revert if not), decrements sender balance, increments recipient balance, STOP.
- `balanceOf(address)` (selector `70a08231`): Loads balance from storage for given address, returns as uint256.

Storage layout — use simplified direct-address indexing:
- Balance of address X is stored at `storage[int.from_bytes(address_bytes, 'big')]`
- Add `# SIMPLIFIED: Real Solidity uses keccak256(abi.encode(address, slot)) for mapping keys. We use the address itself as the storage key to avoid requiring SHA3 opcode.`

Add a constant `INITIAL_SUPPLY = 1_000_000` (in smallest token units).

Add helper functions:
- `encode_transfer(to_address: bytes, amount: int) -> bytes` — selector + encode_address(to) + encode_uint256(amount)
- `encode_balance_of(address: bytes) -> bytes` — selector + encode_address(address)

These helpers should use `compute_selector` and encoding functions from `abi.py`.
